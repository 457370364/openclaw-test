## 智能体安全风险

常见的智能体系统由**基座模型（LLM）**、**记忆模块**、**知识库/向量数据库**、**工具调用（API/插件）**以及**多智能体通信机制**等组件构成。相应地，攻击面也从针对 LLM 的直接注入攻击，扩展到了记忆投毒、工具投毒与通信投毒等多维度风险。

### 1. 直接注入攻击
攻击者通过用户输入嵌入恶意指令或对抗性提示，诱导智能体偏离既定目标或绕过策略约束，进而导致敏感信息泄露、越权操作等后果。典型形式包括**提示注入**[2]与**越狱攻击**[3]。

### 2. 记忆与知识库投毒
攻击者向长期记忆、知识库或向量数据库注入恶意或误导性内容，使智能体在后续检索与推理中引用被污染的信息，从而造成一系列危害[4]。

### 3. 工具投毒
针对智能体可调用的外部工具、API 或插件实施攻击，例如篡改工具返回结果、修改工具描述，或利用工具链参数进行注入[5]。

### 4. 通信投毒
在多智能体系统中，攻击者操纵智能体间通信内容或信道（如中间人智能体攻击[6,7]），传播虚假信息、插入恶意指令或扰乱协作流程。

### 5. 恶意智能体
多智能体系统内部可能存在目标不一致甚至具有对抗意图的智能体（例如被攻陷节点或第三方智能体）。其可通过选择性隐瞒或传递虚假信息、诱导其他智能体执行高风险操作等方式破坏协作机制，进而威胁系统整体性能与公平性[8,9]。
